# Dattatreya M K — Portfolio

Personal portfolio website for Dattatreya M K — CSE undergraduate building at the intersection of software engineering, fintech, and quantitative finance.
LIVE: [https://portfolio-website-not-seven.vercel.app/](https://portfolio-website-sigma-eight-15.vercel.app/)

## Built With

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **TypeScript**: TS 5.7

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deploying to Vercel via GitHub

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "Clean portfolio repository ready for Vercel deployment"
   git push origin main
   ```
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository (`dattatreya-07/Portfolio_Website`).
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**. No special build settings or environment variables are required!
